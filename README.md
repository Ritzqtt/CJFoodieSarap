# CJFoodieSarap

Mobile-first marketing website for **CJFoodieSarap**, a budget-friendly party catering business in Taguig, Philippines. Party trays, bilao sets, and packed meals — serving customers since 2018.

Built with **Vite + React + Tailwind CSS v4**. No backend: the menu is plain component state, and the inquiry form composes a message that opens Messenger or the visitor's email app.

## Quick start

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

### Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the Vite dev server with hot reload |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |

## Editing content

**Almost everything lives in [`src/data.js`](src/data.js).** Update that one file to change:

- Brand name, logo, taglines, and "since" year (`BRAND`)
- Phone, email, social links, address, and delivery note (`CONTACT`, `SOCIALS`)
- Navigation labels (`NAV_LINKS`) and hero tiles (`HERO_TILES`)
- Tray sizes and price groups (`TRAY_SIZES`, `PRICE_GROUPS`)
- À la carte categories, dishes, notes, and dessert extras (`MENU_CATEGORIES`)
- Party tray packages (`PACKAGES`)
- Bilao sets (`BILAOS`)
- Packed meals (`PACKED_MEALS`)
- How-to-book steps (`STEPS`)

Prices are plain numbers in Philippine pesos and are formatted with `formatPeso()` (₱ + thousands separators). Messenger links are generated by `messengerUrl()`, `packageInquiryUrl()`, and `bilaoInquiryUrl()`.

### Before going live

1. **Photos** — replace every placeholder marked `Photo placeholder`, `Photo`, or `Replace with your photo`. The hero photo block is in `src/components/Hero.jsx`.
2. **Hours** — `CONTACT.hours` is set to `[confirm hours]` because Facebook only lists "Always open". Update it, along with `Contact.jsx` and `Footer.jsx` if the wording changes.
3. **Map** — the Contact section uses a real Google Maps embed; update `CONTACT.mapEmbedUrl` and `CONTACT.mapLink` if the location changes.
4. **Social preview image** — add a real 1200×630 photo as `public/og-image.jpg` (the Open Graph tag in `index.html` points to `og-image.jpg`).
5. **Favicon** — the page currently uses an inline SVG favicon in `index.html`; swap it for a real logo file if preferred.

## Form behavior

The inquiry form validates name, PH mobile number (`09XXXXXXXXX` or `639XXXXXXXXX`), event date, guest count, order interest, and delivery address. On submit it opens:

- **Messenger** with the full inquiry pre-filled, or
- the visitor's **email app** with a pre-filled `mailto:` message.

A copy-ready message appears after a valid submit as a fallback. Nothing is stored or sent to a server.

## Design notes

- Colors and fonts are CSS variables under `@theme` in `src/index.css` — edit them there to restyle the whole site.
- Mobile-first breakpoints; the desktop nav and mobile sticky bar switch at `lg` (1024px).
- Keyboard-friendly tabs (arrow keys, Home/End), visible focus rings, skip link, and reduced-motion support.
- SEO includes descriptive title/meta, Open Graph/Twitter tags, and `Restaurant` JSON-LD with contact details and `areaServed` for Taguig and Makati.
